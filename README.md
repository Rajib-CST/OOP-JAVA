# OOP-JAVA Exercises

This repository contains Java exercises arranged in numbered folders. The folder ranges are organized as follows:

| Folders | Topic |
| --- | --- |
| `EX1`-`EX17` | Fundamentals of OOP |
| `EX18`-`EX26` | Access modifiers and encapsulation |
| `EX27`-`EX35` | Classes, properties, and static members |
| `EX36`-`EX48` | Inheritance |
| `EX49`-`EX58` | Polymorphism |
| `EX59`-`EX68` | Interfaces and abstract classes |
| `EX69`-`EX74` | Special methods and the Object class |
| `EX75`-`EX80` | Advanced OOP concepts |
| `EX81`-`EX86` | Generics |
| `EX87`-`EX91` | Exception handling |
| `EX92`-`EX104` | Design patterns |
| `EX105`-`EX115` | Sample projects |
